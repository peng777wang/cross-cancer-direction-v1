# 五条局限解决过程的科学性复核（自审）

日期：2026-09-14
方法：对每一步问三个固定问题——**单位/尺度对不对？假设有没有被检验？判据是否恰当？**——
并把发现的问题连同修正一起记录。下面是结果，包括我自己上一轮做错的地方。

## 发现并修正的问题（5 个，按严重度排序）

### 【实质错误 1】局限 2：eQTL 的尺度未经验证就使用

**原做法**：默认 eQTL 的 β 是"反正态化表达的 1 个 SD"，并用 log2(TPM+1) 的标准差当标定。
**这是一个没有检验的假设**，如果错了，cis-MR 的整个尺度会差一个因子。

**审计做了两个决定性检验**（都在真实数据上，不依赖文档声明）：

1. **每等位 vs 每 SD 基因型**：若是"每等位"，则 se ∝ 1/√(2p(1−p))。
   实测 corr(se, 1/√(2p(1−p))) = **0.996**，且 se·√(2p(1−p)) 在四个频率分位组间
   CV 仅 **4%**（0.0132/0.0132/0.0133/0.0135）→ **确认是"每等位"**。
2. **是否反正态化（INT）**：INT 使表型方差恒为 1，因此由 se 反推的残差 SD
   （σ̂ = se·√N·√(2p(1−p))）**不可能超过 1**。
   在 593 个基因上实测：σ̂ 范围 0.208–0.984，**超过 1 的比例 = 0.0%**，且在 0.95–1.00
   处堆积 → **确认表型经过 INT**。（若表型是 log2(TPM+1)，必然出现 σ̂>1 的基因。）

**结论**：原判定"β 是每等位、以 INT 表达的 SD 为单位"**正确**，无需改结论。

**但标定方式要改**（这是审计带来的改进）：INT 是保序变换，所以**1 SD 精确等于
"中位数→84 分位"区间**，用分位数表达不需要假设底层尺度：

| 标定方式 | 结果 |
|---|---|
| **分位数锚（主用，无假设）** | P50 = 13.74 TPM，P84 = 16.84 TPM → **1 SD = 1.226 倍** |
| log2(TPM+1) SD 交叉验证 | 0.338 log2 单位 = 1.210 倍（两者一致） |
| 仪器全纯合对比 | 0.216 SD = **1.045 倍** |
| 每 2 倍相当于 | **15.7 倍**于仪器实际跨越范围（原报 13.7，已更正） |

### 【实质错误 2】局限 3：判据不恰当，导致我上一轮**高估了稳健性**

**原做法**：用"p > 0.05"作为结论失效的唯一判据，据此写"需要 δ ≥ 0.2–0.5 SD 才翻转"。

**审计发现**：δ 增大时估计量塌向 0，同时 SE 也缩小，于是出现**伪显著**——
例如 LUAD 在 δ=1.0 时 θ = **−0.013**、p = 0.0065，仍"显著"，但这个数字已无实际意义。
也就是说，只看 p 值会得出"极其稳健"的错误印象。

**修正**：同时使用两个判据，并细化 δ 网格（0–1.0，15 档）：

| 判据 | LUAD | LUSC | SCLC | FinnGen 肺癌 | FinnGen COPD |
|---|---|---|---|---|---|
| **幅度减半**（效应量判据） | δ ≈ 0.04 | 0.04 | 0.03 | 0.04 | 0.03 |
| 显著性丧失 | δ > 1.0 | 0.50 | 0.15 | > 1.0 | 0.15 |

**必须写进论文的话（与上一轮不同）**：方向与显著性稳健，但**幅度不稳健**——
吸烟工具只要对 IREB2 有 **δ ≈ 0.03–0.04 SD 的直接效应**（约为 cis 效应的 28–37%），
估计幅度就会减半（虽然方向不变、仍显著）。原表述"需要 δ ≥ 0.2–0.5"是错的，已推翻。

### 【实质错误 3】局限 4：阳性对照被功效混淆

**原做法**：用"14 个 GSCAN 全基因组显著吸烟位点只有 3/14 在 FinnGen SMOKING 复现"作为主证据。

**审计发现**：FinnGen SMOKING 只有 **4,271 例**，对该效应的功效极低；低复现率**可能只是没功效**，
不能证明表型错标。这是一个典型的混淆。

**修正**：改用**不依赖功效**的效应量不相容性检验，同一变异 rs7359276：

| 数据源 | β (se) | OR [95% CI] |
|---|---|---|
| GSCAN 吸烟启动（123 万人） | −0.0007 (0.0021) | **0.999 [0.995, 1.003]** |
| FinnGen SMOKING | +0.1400 (0.0258) | **1.150 [1.094, 1.210]** |

两者差异 = 0.1407 (se 0.0259) → **z = 5.43，P = 5.6×10⁻⁸**。
即：该终点在 15q25 的强信号被 123 万人量级的吸烟行为 GWAS 直接排除。
复现率（3/14）降为辅助证据，并明确标注功效限制。

### 【遗漏 4】局限 5：可信集阈值没有做敏感性

**原做法**：只用 p_e < 1e-5（52 个 SNP）定义可信集，阈值本身是任意的。

**修正**：补做 1e-6（14 SNP）与 1e-4（119 SNP）：

| trait | 阈值 | n SNP | 平均 \|r\| | Wald 中位 | IQR | Q | Q 零模型中位 | **Q 的 P** |
|---|---|---|---|---|---|---|---|---|
| LUAD | 1e-6 | 14 | 0.936 | −1.868 | 0.105 | 0.32 | 1.45 | **0.82** |
| LUAD | 1e-5 | 52 | 0.905 | −1.818 | 0.149 | 5.55 | 5.37 | **0.49** |
| LUAD | 1e-4 | 119 | 0.782 | −1.804 | 0.358 | 21.1 | 13.7 | **0.35** |
| LUSC | 1e-6 / 1e-5 / 1e-4 | 14 / 52 / 102 | | −2.426 / −2.429 / −2.416 | | | | **0.79 / 0.45 / 0.46** |
| SCLC | 1e-6 / 1e-5 / 1e-4 | 14 / 52 / 120 | | −2.634 / −2.574 / −2.545 | | | | **0.81 / 0.60 / 0.64** |

结论在三个阈值下一致：Wald 中位稳定在 −1.80…−1.87 / −2.42 / −2.55…−2.63，
**异质性检验在任何阈值下都不显著**（P = 0.35–0.81），条件后 z 不变（4.25 / 6.04 / 4.07）。

### 【报告精度 5】局限 1："漂移 0.0%" 是四舍五入

**修正**：改为精确核验。恒等式 PP.H4/PP.H3 = r/K 的**最大相对偏差 = 3.3×10⁻¹³**；
K 在 25 组先验下一致到 10 位以上有效数字（如 IREB2×信号 B：K = 38.694213，范围
38.694213…38.694213）。这不是"约等于 0"，是数值精确。

## 两条必须写明的检验方向（不改结论）

**（1）局限 5 的 Q 零分布条件于观测到的表达估计。** 若把 b_e 的抽样误差也纳入模拟，
零分布会更宽、检验更保守。因为我们的结论是**没有拒绝同质性**，这个方向只会让结论更强，
不会削弱它。同时已写明该检验在本位点功效有限（52 个 SNP 平均 |r| = 0.905），
它排除的是"较大的异质性"，不是同一位置上的等位异质性。

**（2）局限 5 的条件分析用单 SNP 条件公式（GCTA 式）**，要求同一样本、同一 N，
并依赖 1000G 参考 LD（n = 503，有抽样噪声）。已报告 eQTL 主变异与信号 A 的
**|r| = 0.442**（透明），并据此把条件估计当作稳健性证据而非精确数值。
