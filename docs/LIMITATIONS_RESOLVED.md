# 五条统计局限：逐条做掉（不是写进局限）

日期：2026-09-14　｜　每条都给出「方法 → 数字 → 结论 → 可追溯文件」

上一版把这些当作"必须写进论文的局限"。这一版把它们变成**可交付的分析**：能测的去测，
测不了的给出精确的临界值（tipping point），让审稿人看到边界在哪里，而不是看到一句"我们做不到"。

## 局限 1｜PP.H4 依赖 p12 先验

**做法**：不再只报三个先验下的三个数，而是把先验网格全部算出来（p1=p2 ∈ {1e-6…1e-2} ×
p12 ∈ {1e-8…1e-4}，共 25 组），并利用 coloc 的解析结构：H4/H3 的优势比只通过**一个比值**
r = p12/(p1·p2) 依赖先验。

**关键数字**（`outputs/lim1/lim1_tipping_points.csv`）

| 配对 | K = (Σe1Σe2−Σe1e2)/Σe1e2 | K 在 25 组先验间的漂移 | H4 超过 H3 的临界 r | coloc 默认 r=1000 时 |
|---|---|---|---|---|
| IREB2 eQTL × **信号 B**（rs28498264） | **38.69** | **0.0%** | r > 38.7 | **PP.H4 = 0.962**（PP.H3 = 0.037） |
| IREB2 eQTL × 信号 A（吸烟，rs4887067） | 51,430 | 0.0% | r > 51,430 | PP.H4 = 0.019（PP.H3 = 0.963） |
| CHRNA5 eQTL × 信号 A（阴性对照） | 2.0×10¹⁰ | 0.0% | — | PP.H4 ≈ 0 |

PP.H4 阈值对应的 r：0.5 → 38.1；0.8 → **220.6**；0.95 → 896.2。

**结论（可直接写进正文）**：K 在全部 25 组先验下**完全恒定**（漂移 0.0%），证明 H3/H4 的取舍只
取决于 r；coloc 的默认设定 r = 1000 已高于信号 B 的临界值 38.7 约 26 倍，也高于 PP.H4>0.8 所需的
220.6 约 4.5 倍。而"eQTL 与吸烟信号 A 不共定位"这一条更稳：它只有在 r > 51,430 时才可能翻转，
也就是要求研究者把"共享变异"的先验优势设成比常规高 5 万倍——不成立。

**可追溯**：`work/lim1_coloc_prior_grid.R`（服务器运行）→ `outputs/lim1/lim1_prior_grid.csv`
→ `work/lim1_summarise.py` → `outputs/lim1/lim1_tipping_points.csv`

## 局限 2｜MR 效应的单位不可解释（不是"每 2 倍"）

**做法**：单位不是假设出来的，**先检验再标定**。（i）由 se 与等位频率的关系确认 β 是"每等位"
（corr(se, 1/√(2p(1−p))) = **0.996**，se·√(2p(1−p)) 在频率分位间 CV 仅 **4%**）；
（ii）在 **593 个基因**上做上限检验确认表型经过反正态化（INT）：由 se 反推的残差 SD 最大
**0.984，无一超过 1**——只有方差恒为 1 的表型才可能，这是 INT 的指纹；
（iii）**INT 保序**，因此 1 SD 精确等于"中位数→84 分位"区间，用分位数标定**不需要假设底层尺度**。

**关键数字**（`outputs/lim2/lim2_expression_scale_facts.csv`）

| 量 | 值 |
|---|---|
| 肺组织 IREB2 表达（n = 604，GTEx API） | P50 = 13.74 TPM，P84 = 16.84 TPM |
| **1 SD = P84/P50 = 1.226 倍** | 分位数锚（无假设）；log2(TPM+1) SD 交叉验证 = 1.210 倍，一致 |
| v8 与 v10 中位 TPM 差 | 2.1%（13.46 vs 13.74）→ 标定对版本不敏感 |
| cis 工具全纯合对比度 | 2×\|β\| = 0.216 SD = **1.045 倍**（仅 4.5% 变化） |
| 2 倍变化相当于 | 3.41 SD，是工具实际跨越范围的 **15.7 倍**（外推） |

换算后的效应（`outputs/lim2/lim2_mr_units.csv`）：

| 结局 | 每 1 SD（=1.226 倍）OR | 在工具真实覆盖范围内（1.045 倍）OR | 每 2 倍（外推）OR |
|---|---|---|---|
| LUAD | 0.162 | **0.675** | 0.002 |
| LUSC | 0.096 | **0.602** | 0.0003 |
| SCLC | 0.076 | **0.572** | 0.0002 |
| FinnGen 肺癌 | 0.124 | **0.636** | 0.001 |
| FinnGen COPD | 0.260 | **0.747** | 0.010 |

**结论**：把"每 1 SD"锚定为"每 1.226 倍表达"（分位数锚，无假设），并同时报告工具真实覆盖
范围内的 OR（0.57–0.75，数量级合理）。"每 2 倍"的外推值一并列出但明确标注外推 **15.7 倍**——
审稿人看到的是量化的边界，而不是一句含糊的免责声明。

**可追溯**：`work/lim2_expression_scale.py`（调用 GTEx 官方 API，可重跑）

## 局限 3｜14 个吸烟工具"不影响 IREB2 表达"这一假设无法检验

**做法**：承认这个假设在本数据里测不了（GTEx 只有 cis 结果），于是**把假设换成有临界值的界**：
让全部 14 个吸烟工具对 IREB2 表达都有相同的直接效应 δ（同号 = 最坏情形），遍历 15 档 δ 重算
MVMR。判据用两个：① 显著性丧失；② 更严格的**幅度减半**——因为 δ 很大时估计量塌向 0、SE 同时
缩小，会出现 θ = −0.013 却 p = 0.0065 的**伪显著**，只看 p 值会错误地得出"极其稳健"的印象。

**关键数字**（`outputs/lim34/lim3_trans_tipping_points.csv`）

| 结局 | δ=0 | δ=0.05 | **幅度减半所需 δ** | 显著性丧失所需 δ |
|---|---|---|---|---|
| LUAD | −1.82 | −0.58 | **0.04** | > 1.0 |
| LUSC | −2.35 | −0.65 | **0.04** | 0.50 |
| SCLC | −2.58 | −0.55 | **0.03** | 0.15 |
| FinnGen 肺癌 | −2.09 | −0.63 | **0.04** | > 1.0 |
| FinnGen COPD | −1.35 | −0.26 | **0.03** | 0.15 |

**参照量级**：cis eQTL 效应本身只有 **0.108 SD/等位**；14 个吸烟工具对吸烟的效应是
0.012–0.019/等位。δ = 0.15（显著性丧失线）是 cis 效应的 1.4 倍；δ = 0.03（幅度减半线）
只有 cis 效应的约 28%。

**结论（已更正）**：**方向与显著性稳健，但幅度不稳健**。方向在 δ 一直到 1.0 都不翻转；
显著性要到 δ ≈ 0.15–0.50 才丧失。但**幅度在 δ ≈ 0.03–0.04 SD 就已减半**，而 δ = 0.03 只有
cis 效应（0.108 SD）的约 28%，落在真实 trans-eQTL 的量级之内。因此论文中必须写：幅度应视为
**在上界意义下的估计**，未测量的 trans 效应只会使其衰减。

**可追溯**：`work/lim3_lim4_assumptions.py` → `outputs/lim34/lim3_trans_bias_bound.csv`

## 局限 4｜FinnGen 的 SMOKING 是诊断型终点，与 GSCAN 不一致

**做法**：不靠"复现率"下结论——该终点只有 4,271 例，功效极低，低复现率**可能只是没功效**，
用它当证据是混淆。改用**不依赖功效**的效应量不相容性检验，再用复现率作为辅助证据。

**主证据：同一变异的效应量互不相容**（`lim4_positive_control_finngen_smoking.csv`）

| 变异 rs7359276 | β (se) | OR [95% CI] |
|---|---|---|
| GSCAN 吸烟启动（123 万人） | −0.0007 (0.0021) | **0.999 [0.995, 1.003]** |
| FinnGen SMOKING | +0.1400 (0.0258) | **1.150 [1.094, 1.210]** |

两者差异 = 0.1407（se 0.0259）→ **z = 5.43，P = 5.6×10⁻⁸**。
即该终点在 15q25 的信号被 123 万人量级的吸烟行为 GWAS 直接排除，**与功效无关**。

**辅助证据**：14 个 GSCAN 全基因组显著吸烟位点在该终点只有 **3/14 达 p<0.05、0/14 达全基因组
显著**（并已标注：该终点仅 4,271 例，此项受功效限制，不作为主证据）。

**并且没有任何结果依赖它**：全部估计只用 GSCAN。把 14 个工具随机分成两半分别估计
（`outputs/lim34/lim4_split_half.csv`）：
IREB2 效应在两半之间差异 < 0.01（如 LUAD −1.819 vs −1.818），留一法范围 −1.819…−1.817；
吸烟项在两半中方向一致（0.52–1.95），仅精度有波动。

**结论**：该终点被正式排除，且有阳性对照证据；结论完全不依赖它。

## 局限 5｜cis 区只有一个独立 eQTL 信号，cis-MR 依赖单变异

**做法**：把它拆成四个可测的问题——结构、工具选择、多 SNP 估计、异质性与条件分析。
五种测量全部在 52 个可信集 SNP 上完成（eQTL p<1e-5）。

**关键数字**（`outputs/lim5/lim5_results.csv`）

| 测量 | 结果 |
|---|---|
| 结构：可信集内部相关性 | 平均 \|r\| = **0.905**，最小 0.54，最大 1.00 → **确实只有一个 LD 块，不存在第二个独立工具** |
| 工具选择（换任何 SNP 做工具） | Wald 比：LUSC 中位 −2.43（IQR 0.19，范围 −2.74…−1.83）；SCLC 中位 −2.57（IQR 0.25）→ 结论不取决于选哪个变异 |
| 去掉哨兵 / 去掉最强 5 个 | 中位数变化 < 0.02 |
| 异质性（Cochran Q，LD 感知蒙特卡洛零分布） | Q = 5.5，零模型 P = **0.49 / 0.45 / 0.60** → 无显著异质性，与"单一共享因果变异通过表达起作用"一致 |
| **阈值敏感性**（可信集定义 p_e < 1e-6 / 1e-5 / 1e-4） | n = 14 / 52 / 119；Wald 中位 −1.87 / −1.82 / −1.80（LUAD）、−2.43 / −2.43 / −2.42（LUSC）、−2.63 / −2.57 / −2.55（SCLC）；**Q 的 P = 0.35–0.81，全部不显著** → 结论不依赖阈值 |
| 条件于独立吸烟信号（rs16969968）后 | cis-MR 仍显著：z = **4.07 / 4.25 / 6.04**（P = 5×10⁻⁵ … 1.5×10⁻⁹） |
| 高效率多 SNP（GLS/SMR）估计量 | **在本位点不可用**：LD 有效秩 26/52、条件数 4.7×10³⁰¹、bootstrap SD >500 → 如实报告为位点性质，不作宣称 |

**结论**：本条局限的两个真正威胁被逐一排除——(i) 结论不依赖选哪个变异；(ii) 条件掉区内第二个
独立 GWAS 信号（吸烟信号）后 cis-MR 依然显著。同时诚实说明：本区不存在第二个独立工具，
因此不能宣称"多 SNP 估计提升了精度"。

**可追溯**：`work/lim5_cis_heterogeneity.py`（服务器运行）→ `outputs/lim5/*`

## 一句话总览（已按自审结果更正）

| 局限 | 状态 | 关键数字 |
|---|---|---|
| 1 共定位依赖 p12 | **精确解决** | 只依赖 r = p12/(p1p2)；K = 38.694；默认 r=1000 → PP.H4 = 0.962；恒等式偏差 3×10⁻¹³ |
| 2 表达尺度不可解释 | **实测锚定（含尺度检验）** | 1 SD = 1.226 倍（INT 上限检验通过）；工具实际只跨 1.045 倍 |
| 3 trans 效应假设 | **有临界值的界** | 方向/显著性稳健至 δ≈0.15–0.5；**幅度在 δ≈0.03–0.04 即减半** |
| 4 吸烟表型不一致 | **不相容性检验排除** | 同一变异两表型差 z = 5.43（P = 5.6×10⁻⁸）；复现率仅作辅助 |
| 5 单变异工具 | **四条证据 + 阈值稳健** | 52 SNP 一个 LD 块（平均\|r\|=0.905）；Q 在三个阈值下 P=0.35–0.81；条件后 z=4.07–6.04 |

**仍未测、但已给出边界的**：局限 3 的 trans 效应本身（本数据集无 trans-eQTL），局限 5 的
多 SNP 精确估计量（本位点 LD 近奇异）。两者都在上面写明了原因和临界值，不含未标注的外推。

**本轮自审（见 `AUDIT_selfcheck_limitations.md`）发现并修正了 5 个问题**，其中 3 个是实质性的：
局限 2 的尺度此前未经验证即使用（现已通过"每等位"与"INT"两项检验，并把标定换成无假设的分位数锚）；
局限 3 只用 p 值判定失效，导致**高估了幅度稳健性**（现增加"幅度减半"判据，结论改为"幅度不稳健"）；
局限 4 的阳性对照受终点功效混淆（现改用不依赖功效的效应量不相容性检验）。
